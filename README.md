# RxDate

Android pharmacy utility project for exploring expiration date, beyond-use-date, and date calculation workflows.

## Overview

RxDate is a Kotlin-based Android project built to explore pharmacy date calculations and workflow support tools. The project focuses on turning repeated operational date checks into a simple mobile utility.

## Features

- Date calculation workflows
- Expiration / BUD support concepts
- Mobile-first pharmacy utility design
- Simple technician-facing UI
- Kotlin Android implementation

## Tech Stack

- Kotlin
- Android
- Android Studio

## What This Demonstrates

- Healthcare workflow thinking
- Mobile utility development
- Practical pharmacy operations knowledge
- User-focused tool design
